# FitLog 🏋️

FitLog is a modern and responsive workout management web application. 
It allows users to explore workouts, view detailed exercise information, 
add workouts to today's plan, save workouts for later, and track completed exercises.

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React
- REST API
- LocalStorage
- Git & GitHub

## ✨ Key Features

### 1. Workout Library
Explore a collection of workouts with useful information such as:
- Workout name
- Muscle groups
- Equipment
- Duration
- Calories burned
- Rating

### 2. Workout Details
View detailed information about each exercise, including:
- Description
- Muscle groups
- Equipment
- Difficulty
- Sets and reps
- Duration
- Calories
- Rating
- Step-by-step instructions

### 3. My Plan
Create and manage today's workout plan.

Users can:
- Add workouts to today's plan
- View planned exercises
- Track total exercises, minutes, and calories
- Mark workouts as completed
- Remove workouts from the plan

### 4. Save for Later
Save favorite workouts for later and access them from the Saved tab.

Users can:
- Save workouts
- View saved workouts
- Open workout details
- Remove saved workouts

### 5. Responsive & Interactive Design
FitLog provides a responsive and user-friendly experience across:
- Mobile
- Tablet
- Desktop

The application also includes loading states, toast notifications, sorting options, interactive buttons, and persistent workout data using LocalStorage.
